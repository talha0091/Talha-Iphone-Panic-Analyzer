# iPhone Panic Log Analyzer

A Windows desktop utility designed for mobile technicians and repair shops to automate the extraction and analysis of iPhone panic logs. 

If you regularly deal with iPhones stuck in the classic "3-minute restart loop," this tool eliminates the need to manually extract `panic-full` logs and hunt down hex codes. It reads the device logs and instantly translates the data into a plain-English hardware diagnosis (e.g., "Charging Port Flex" or "Front Dynamic Highlight Proximity Sensor").

## 🚀 Key Features

* **1-Click Auto-Extract:** Connect the iPhone via USB, hit "Run Diagnostic Scan," and the tool automatically pulls all available panic logs from the device within seconds.
* **Direct Hardware Diagnosis:** Automatically parses the log files and tells you exactly which component is failing, allowing you to go straight to the board-level or flex-cable repair.
* **Stolen Device Protection (SDP) Bypass:** If an iPhone has SDP enabled and blocks USB data connections to your PC, you can use the **Import** feature. Simply share the log file to yourself via AirDrop or WhatsApp, drop it into the tool, and read it perfectly.
* **Legacy Code Search:** Includes a manual entry tab for technicians who want to manually search a specific hex code (e.g., `0x419434`) from a previously saved log.

## 🛠️ How to Use

### Method 1: Direct USB Connection (Standard)
1. Launch `iPhone Panic Log Analyzer.exe`.
2. Connect the problematic iPhone to your Windows PC via USB.
3. Click **Run Diagnostic Scan**.
4. Select the most recent log file generated by the device.
5. Read the diagnostic result at the bottom of the screen to identify the faulty flex/sensor.

### Method 2: Import Mode (For Stolen Device Protection)
1. On the iPhone, navigate to `Settings > Privacy & Security > Analytics & Improvements > Analytics Data`.
2. Find the most recent `panic-full` file.
3. AirDrop, email, or WhatsApp the file to your PC.
4. In the Panic Log Analyzer, click **Import** and select the file.
5. The diagnostic result will populate instantly.
